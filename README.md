# Data Analytics Laboratory – README

## Overview

This repository contains the implementation of **12 Data Analytics Laboratory experiments** using **R**, **Python**, and **JMP Pro**. The experiments demonstrate fundamental data analysis techniques such as descriptive statistics, correlation analysis, regression, hypothesis testing, time series analysis, ANOVA, and non-parametric tests.

The programs are intended for educational purposes and follow the Data Analytics Laboratory syllabus.

---

## Technologies Used

* R Programming
* Python 3.x
* Jupyter Notebook
* JMP Pro
* RStudio (Optional)

## How to Run

### R Programs (Experiments 1–8 and 12)

1. Open **RStudio** or **Jupyter Notebook** with the R kernel.
2. Copy and paste the required experiment code.
3. If prompted, select the corresponding dataset using `file.choose()`.
4. Run the program.
5. Observe the generated tables, statistical results, and plots.

### Python Programs (Experiments 9–11)

1. Open **Jupyter Notebook**.
2. Create a new Python notebook.
3. Copy and paste the experiment code.
4. Install the required libraries if they are not already available.
5. Run all cells to obtain the output and graphs.

### JMP Pro Experiments

1. Open JMP Pro.
2. Load the required dataset.
3. Follow the experiment procedure described in the laboratory manual.
4. Generate the required statistical reports and visualizations.
